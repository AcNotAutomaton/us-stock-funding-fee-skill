# Calculation Rules

## Variables
- `A`: 输入金额
- `C`: `USD`/`HKD`
- `R`: USDHKD，默认 `7.8`
- `D`: `inflow`/`outflow`

若 `C=USD`：`A_usd=A`，`A_hkd=A*R`
若 `C=HKD`：`A_hkd=A`，`A_usd=A/R`

## D = inflow（汇丰香港 -> 嘉信）
以下为用户截图参考模型，仅用于标明假设的演算；不能当作当前官方全程报价。路径及可用性见 `route-catalog.md`。

1. 方案一（港币直入，嘉信换汇）：`fee1_usd = A_usd * 0.0016`，此处 fee 表示估计汇损，非单列手续费。
2. 方案二（美元直接电汇）：`fee2_usd = 21.88`，固定费用假设，覆盖范围待核实。
3. 方案三（港币经 Wise 换美元，嘉信 ACH 拉取）：`fee3_usd = A_usd * 0.004`，参考兑换成本；拉取 USD 段按用户说明为零费用。汇丰到 Wise 的 HKD 转账费若存在则另加，不能把 USD 拉取无损误写为 HKD 全程无损。
4. 方案四（美元经 Wise，嘉信 ACH 拉取）：`fee4_hkd = 10`（`fee4_usd = 10 / R`）。用户 2026-09-26 提供该模型；2026-10-10 核查明确：使用 Wise 香港多币种收款资料并经汇丰本地 RTGS／CHATS 汇 USD 时，汇丰本行发汇费 0，10 HKD 或等值是 Wise 的 CHATS 收款费。Wise USD 到嘉信的拉取段按用户说明为零费用、无换汇。不能推广至国际 SWIFT；其他费用按实际另列。依据见 `route-catalog.md`。
5. 方案五（汇丰香港 → 汇丰美国 → 嘉信）：`fee5_usd = 0`，符合各段免费条件时的转账费，不含换汇及账户维护成本。

`currency` 默认表示现持资金币种。方案一、三从 HKD 出发，方案二、四、五从 USD 出发；币种不符时须计入前置换汇，缺少报价则明确全程成本未知。`R` 仅为比较基准，不代表银行或 Wise 的可成交汇率。不得把基准折算视为免费换汇。已有实际报价时单列实际成本及其来源，与截图模型分开；推荐仅比较可用且费用口径一致的方案。

### 按初始币种选择（用户已明确）

- 初始 HKD：默认只比较一、三。仅按上述比例成本，一的 0.16% 低于三的 0.4%，一优先，差额为初始 HKD 金额的 0.24%；正金额范围不存在金额交叉点。额外转账费或实际兑换报价不同时重新比较。
- 初始 USD：默认只比较二、四、五。在免费条件满足且已有可用 HSBC US 账户时，五的模型成本最低；无 HSBC US 但 Wise 关联及扣款可用时，四优先；需要直接电汇或其他路径不可用时考虑二。在默认 R=7.8 下，四约 1.28 USD，低于二的 21.88 USD；这些均是固定成本，模型内不存在随金额变化的交叉点。
- 资格未知时给条件式选择，不假定用户拥有 HSBC US 或可用 Wise 关联。五的零转账费不代表值得为此另开或维护账户；开户及维护成本未包含在模型中。
- 五项仍全部展示，非对应初始币种的方案注明“初始币种不匹配，不参与本次默认排名”。用户要求跨组比较时，加入实际前置兑换费及汇差；R 不能代替成交报价。

原先一与二的 `21.88 / 0.0016 = 13,675 USD` 只是不同初始币种模型的数学相等点，不是本任务有效的选路交叉点；默认输出不再用它作选择依据。

## D = outflow（嘉信 -> 汇丰香港）
1. 方案一：`15~50 USD`
2. 方案二：`9.57 USD`
3. 方案三：`A_usd * 0.003`
4. 方案四：`0`（需 HSBC US）
5. 方案五：`2 USD`（IBKR 换汇费）

交叉点（方案二 vs 三）：
`9.57 / 0.003 = 3190 USD`
- `A_usd > 3190`：通常方案二更低
- `A_usd < 3190`：通常方案三更低
