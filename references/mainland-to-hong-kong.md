# 内地银行汇款至香港：美元／港币免手续费路径

核查日期：2026-10-10。适用于个人账户；银行产品和优惠会调整，实际操作前重新核对。本文编号独立于汇丰香港 → 嘉信五方案，也不同于恒生香港 → 华美的 Global Money+。

阅读定位：路线总览 → M1 汇丰／M2 渣打／M3 恒生 → M4 兴业重点推荐 → M5 工行／M6 中行 → M7 人民币跨境支付通 → M8 建行跨境直联 → 选路、计算与用途边界。

## 范围与费用口径

- USD 原币：内地 USD 现汇 → 香港 USD 账户；HKD 原币：内地 HKD 现汇 → 香港 HKD 账户。保持同币种时不发生兑换，但不据此推定所有转账费用为零。
- RMB → HKD：人民币扣款、港币到账，另列兑换成本；“跨境支付通”不能当作已有美元余额的美元汇款通道，也不能当作已有港币余额的原币通道。
- 全程费用包括汇出手续费、电讯费、代理行费、收款费及可能的钞转汇／兑换费用。OUR／汇款人承担表示费用承担方式，不自动等于银行豁免费用；全额到账也可能是汇款人另付费用。
- 原有外币在另一家内地银行时，先划转到免费通道的汇出银行会形成额外一段；核查该段手续费、可用渠道及资金来源审核，不默认免费。账户等级维护成本另列，不混作该笔汇款费用。

## 路线总览：免费对应的收款银行

免费判断绑定“汇出银行 + 收款银行 + 币种 + 通道 + 本人优惠资格”。以下兴业路线明确指向汇丰香港，不是兴业香港分行，也不是任意香港银行；工行、中行、建行等集团路线分别对应自己的香港银行，不能把“集团同名免费”扩展成汇往汇丰或其他银行也免费。

## M1：汇丰中国 → 汇丰香港（环球转账）

操作路径：在汇丰中国网银／手机银行关联本人汇丰香港账户 → 选择“环球转账同名速汇” → 选择 USD 或 HKD 现汇扣款及同币种收款 → 核对资格、报价和用途后提交。

中国官网明确免费客户包含卓越理财、卓越理财尊尚、环球私人银行；支持币种包括 USD 和 HKD。香港官网亦介绍从海外本人汇丰账户经环球转账汇入香港费用全免。将其作为满足两端条件后的免费候选，不能套用普通 SWIFT 汇款入口的收费或豁免规则。

运筹理财可以使用服务，但中国当前 FAQ 列示同名速汇每笔 US$20 或等值外币；旧 PDF 中“运筹免费”不能覆盖当前收费。只有香港 HSBC One／香港卓越账户，不代表内地端自动符合免费资格。现钞不是现汇；汇丰中国 FAQ 明确环球转账使用外币现汇储蓄账户。

来源：[中国转账产品及客户范围](https://www.hsbc.com.cn/transfer-payments/)、[运筹与卓越收费对照](https://www.hsbc.com.cn/advance/faq/)、[中国存款转账 FAQ](https://www.hsbc.com.cn/help/faqs/deposits-and-transfers/)、[香港海外汇入环球转账说明](https://www.hsbc.com.hk/zh-cn/international/moving-to-hong-kong/)。

## M2：渣打中国 → 渣打香港（全球账户间汇款）

操作路径：中国网银／移动银行“转账 → 选择账户 → 全球账户服务 → 全球账户间汇款” → 本人渣打香港账户 → USD 或 HKD 同币种 → 费用选择“汇款人承担”。以当前 App 入口为准。

优先理财及优先私人理财的官方政策覆盖汇出手续费、电报费和中间代理行费，不限笔数；服务渠道 FAQ 明确满足该费用承担选择可零费用足额到账。不选汇款人承担可能从本金扣海外费用。优逸理财只列免手续费和电报费，不能按同一全免费模型计算。

这是集团同名 Global Link Transfer，不是向任意香港银行的一般电汇。中国产品页确认 USD／HKD 汇往香港可用；如界面显示不同费用或收款端提出额外收费，先核实优惠适用性再估算，不能把异常收费当作零。

来源：[中国全球资金汇款优惠](https://www.sc.com/cn/free-global-fund/)、[中国海外汇款与客户等级](https://www.sc.com/cn/bank-with-us/overseas-remittance/)、[全球账户间汇款操作及足额到账 FAQ](https://www.sc.com/cn/help-centre/faqs-ways-to-bank/)。

## M3：恒生中国 → 恒生香港（跨域转账）

先在恒生香港 Mobile App 登记“跨域查账转账”，关联本人恒生中国账户；然后通过恒生中国 App 的“跨域转账”专用页面向本人香港账户汇出 USD／HKD。香港服务页支持 USD、HKD 等币种及合资格个人单名账户。不能替换为普通汇款页面或柜台“3 小时特快汇款”。

两端信息需合并判断：香港产品页概括两地转账费用全免；内地个人费率表第 8.5 项明确区分等级：

- 内地优越理财：本行手续费、电报费豁免；被扣的海外代理行费如适用会退回。可能先扣后退，分别报告首次入账和退款后的净额，不承诺即时全额。
- 内地优进理财：累计 3 次本行手续费及电报费豁免，人民币和外币共用次数；不包括海外代理行费用，用完按标准收费。不是每年自动重置 3 次。

采用内地具体费率条件，不根据香港“免费”宣传推定所有内地账户等级全免费。另确认香港账户符合专用通道收费豁免。香港页面还要求自 2026-09-29 起地址含城市／市镇字段；操作失败时核查这一项。

来源：[香港跨域查账转账说明](https://www.hangseng.com/zh-cn/personal/banking/cross-border-view-and-transfer/)、[恒生中国个人费率表第 8.5 项及注释](https://www.hangseng.com.cn/1/PA_esf-ca-app-content/content/pws/personal/pdfs/zh_CN/tariff_personal_banking.pdf)。

## M4：重点推荐兴业寰宇人生卡 → 汇丰香港

完整官网页面的“寰宇人生借记卡”专属条款确认：2026-07-01 至 2027-06-30 优惠期内前 30 笔跨境外汇汇款免本行手续费、电讯费，购汇／结汇交易费率享五折，外汇钞转汇费用豁免。普卡面向零售客户，不要求先成为白金／钻石客户；不能仅按通用 VIP 费率或电讯费条目遗漏这项专属权益。免费次数按活动期理解，不写成每月 30 笔或永久免费。

具体路径：资金位于本人兴业寰宇人生卡 → 兴业 App 跨境外币汇款 → 本人汇丰香港 USD／HKD 同币种账户。已有 USD／HKD 现汇直接原币汇出；RMB 起始先在兴业按优惠报价购汇。核对卡种、剩余次数、实际可用渠道及费用后比较；不凭早期“仅柜面”介绍限制当前渠道。

明确免费对应关系：用户确认的是“兴业寰宇人生卡 → 汇丰香港”可全程免费，并认为兴业汇率较好；不是“兴业汇往任何香港银行都免费”。兴业官方确认前 30 笔本行双费减免，汇丰香港官方说明电汇收款可豁免本地手续费；另有 2024-06-12 的美元汇款网络自述称本金无扣费到账，作为可行案例而非每笔交易保证。

将该组合列为重点推荐，尤其适合已有汇丰香港账户、需要人民币购汇再汇港且剩余免费次数充足者。汇率优势的依据是购结汇价差五折优惠；五折不是把汇率乘以 0.5，也不保证优于所有银行。以同一时点、金额、币种的实际 RMB 扣款额和香港净到账额比较；已有美元／港币则不要添加无关兑换。仅持有香港汇丰而没有内地汇丰卓越资格者，也可比较这条非集团通道。

官网仍明确优惠不包含境外银行可能收取的费用。收款行与实际清算路径不扣费时，可按全程零转账费计算；未知时只把境外费用列为待确认，不因此否定免费路径。小额全额到账服务（等值 US$10,000 以内）另收 RMB50／笔，不能为追求“全额到账”默认添加该付费服务，也不能把该费用算成零。

费用承担及代理行资料按本人订单和银行当前指引核对，不照抄个案保证中间费为零。网络教程中的任意酒店地址、固定旅游用途等不作为操作指令：填写真实本人地址和实际用途。若改汇中银香港、工银亚洲、建行亚洲或其他银行，建立新的费用分支，不能沿用本条汇丰香港的零费用结论。

核查时定位完整官网页面的“寰宇人生借记卡”专属段落及注释，不混用同页其他卡种的旧期限；搜索摘要或不完整正文不足以否定专属优惠。

来源：[当前寰宇人生卡完整权益及期限](https://m.cib.com.cn/netbank/cn/personal/debit/index.html)、[兴业通用资费及小额全额到账收费](https://mobile.cib.com.cn/netbank/cn/aboutCIB/about/charges/adjustment/combined.html)、[汇丰香港电汇收款费用说明](https://www.hsbc.com.hk/zh-cn/help/faq/transfers-and-payments/)、[美元全额到账网络个案（2024，未独立核验）](https://shuzimumin.com/t/topic/18)。

## M5：内地工行 → 工银亚洲（工银速汇）

用户明确补充工行及中行可全程免费。这是用户提供的路径信息，并非本次独立核验的到账回单或适用于所有账户的官方承诺；将两条纳入可用的零费用候选，不把“未找到完整条款”写成“实际必收费”。本人有效汇出优惠、收款豁免及无其他扣费均确认后按全程零费用计算。

工行操作：本人内地工行 USD／HKD 账户 → 手机银行工银速汇 → 本人工银亚洲同币种账户。内地产品官网确认免电讯费；工银亚洲 e 账通汇入优惠有效期为 2026-07-01 至 2026-12-31，需在该行手机银行添加并保持至少一个本人内地工行账户；其优惠只覆盖基本汇入费，不含代理行等费用。需核对内地手机银行本人适用汇出优惠、费用确认页及区域条件，不把香港端免汇出优惠反向套用，也不用 2017 年旧活动证明当前资格。

来源：[内地工银速汇产品](https://www.icbc.com.cn/page/721852378969309213.html)、[工银亚洲 e 账通优惠及限制](https://www.icbcasia.com/hk/sc/promotion/mobile-banking-e-account-express-service.html)。

## M6：内地中国银行 → 中银香港（同名境外中行汇款）

中行操作：本人内地中国银行 USD／HKD 账户 → 手机银行向境外中行汇款 → 本人中银香港同币种账户。中银香港指南确认该同名路径免汇入费；用户补充内地端也免费。以当前手机银行本人适用优惠、同名校验及最终费用确认页核实汇出手续费、电讯费和其他费用。未能获取当前完整免费条款时注明这一缺口，不表示否定该方案。2022 年历史免费活动已到期，不能单独作为 2026 年依据；香港中银快汇汇出免费也不能反向套用。

来源：[中银香港南向服务指南](https://www.bochk.com/dam/crossborderservices/25GBAserviceguide_southcross.pdf)、[中行历史优惠及明确到期日（非现行依据）](https://wap.boc.cn/bif/bi3/202112/t20211228_20575165.html)。

## M7：交行 → 建行亚洲（人民币跨境支付通，港币到账）

交行 App 10.0 官方说明确认内地汇向香港零手续费、支持人民币或港币到账。可在支持跨境支付通的内地 App 选择香港收款银行／账户、HKD 到账，查看 RMB 扣款额及汇率；香港收款端是否免费仍应核查，建行亚洲目前公布接收内地人民币／港币转账无需手续费。若目标为汇丰香港，其 FAQ 确认可接收内地港币／人民币，内地端具体费用以汇出银行规则为准。

此通道并非普通香港本地 FPS 转账，也并非美元汇款。人民币兑换港币有银行报价／汇差，手续费为零不代表无损换汇。不为已有 USD／HKD 余额增加“先结汇成人民币再换港币”的不必要步骤。

个人内地汇出需要符合资格、额度和用途；年度等值 US$50,000 的要求见香港银行说明，具体占用口径及可用额度向内地汇出行确认。单笔／单日上限按当前银行页面核查，不把香港 → 内地每日 HK$10,000、每年 HK$200,000 的北向限制反向套用，也不把人民币汇出理解为绕过购付汇监管。

来源：[交行 App 南向零手续费及到账币种](https://m.bankcomm.com/wap/shtml/wap/cn/15539/15633/7048586.shtml?channelId=15539)、[建行亚洲跨境支付通收款免费](https://www.asia.ccb.com/hongkong_sc/personal/banking_channels/faster_payment_system.html)、[汇丰香港跨境支付通收款说明](https://www.hsbc.com.hk/zh-cn/help/faq/transfers-and-payments/)、[恒生跨境支付通内地汇出资格及年度限额](https://www.hangseng.com/zh-cn/personal/banking/payment-connect/)。

## M8：内地建行跨境直联汇款至建行亚洲

操作路径：本人内地建行 USD／HKD 现汇账户 → 内地建行“跨境直联汇款”功能 → 建行亚洲个人同币种账户。收款账号及账户资料按银行当前指引填写，不猜测 SWIFT／账号。使用专用直联通道，不套用普通 SWIFT、陆港通龙卡或人民币跨境理财通的费率。

建行亚洲官方产品页确认该通道支持美元、港币，并豁免汇入手续费至另行通知；用户补充内地端也不收费，因此列为原币全程免费候选。本人内地汇出确认页手续费、电讯费为零且通道无其他费用时，可按全程零转账费／原币全额到账估算。当前本次公开官网核查尚未确认内地端对所有账户统一免费，不将用户说明升级成无条件普遍承诺。

提交前核查本人两端 App 当期优惠、次数与收费提示；若页面有每月首几笔免费限制，应按该笔剩余次数判断，不据“至另行通知”推定无限次免费。人民币起始仍需比较购汇报价；该产品不等于 RMB → HKD 的跨境支付通。

## 选路及到账估算

1. 已有汇丰香港账户的普通内地客户，尤其需人民币购汇后汇港：重点比较 M4“兴业寰宇人生卡 → 汇丰香港”的前 30 笔双费减免及优惠报价，不默认需要内地汇丰卓越等高等级账户；人民币起始、港币小额另比较 M7，最终按实际净到账与总扣款选路。
2. 已有集团两地账户：纳入 M1／M2／M3，以及用户补充的 M5／M6／M8 零费候选；专用通道与本人免费条件满足时优先利用已有账户，不为了推荐兴业而强制中转或开户。
3. 已有普通内资银行的 USD／HKD：比较直接原币汇款与转入其他银行的两段完整成本；各路径未确认的境外费用等保留为未知。用户提供具体报价或到账证据时据此更新该场景，不推广到所有账户。
4. 相同币种本金为 A 时，首次入账 = A − 从本金扣取的费用；香港账户净增加额还需减单独扣账费用并加实际已退费用；汇款人总支出 = A + 本金之外另扣的费用。将费用折为同币种时标明折算依据。
5. USD10,000 或 HKD10,000 经已确认所有免费条件、无兑换的通道，可分别按 10,000 同币种净额估算；任一费用未知时不能输出这个确定数值。恒生代理费待退的情形分别展示首次入账与最终净额。

## 用途与监管边界

内地居民购付汇必须如实申报用途，不得借用额度、虚假申报或分拆规避监管。个人便利化购汇不能用于尚未开放的境外证券投资等资本项目；已有外币、同名香港账户或免手续费通道也不自动豁免汇出用途审查。本文比较内地 → 香港的合法银行转账费用，不证明之后转至嘉信／华美投资符合内地规定；涉及投资用途，先核实适用的获准渠道与要求，不能建议填旅游／生活费掩盖实际投资目的。
