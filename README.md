# us-stock-funding-fee-skill

用于介绍和比较汇丰香港与嘉信（Charles Schwab）之间的资金路径、转账费用和换汇损失。支持单条路径解释、按初始币种选路，以及具体金额的参考成本计算。

## 支持场景

- **入金（inflow）**：汇丰香港 → 嘉信，比较五种路径及适用条件。
- **出金（outflow）**：嘉信 → 汇丰香港。路径映射仍待核实，仅提供标明假设的模型分析，核实前不作确定性的最优路线推荐。

本 skill 用于说明与比较，不执行转账。参考费用不等于当前官方报价。

## 如何使用

可以直接用自然语言提问，不必按固定参数格式输入。

| 任务 | 需要的信息 |
|---|---|
| 介绍五种方案或解释某条路径 | 说明方向或方案，无需金额 |
| 判断适合自己的方案 | 资金方向、初始币种，可补充已有账户条件 |
| 计算具体费用 | 资金方向、正数金额、初始币种（HKD 或 USD） |

“初始币种”指开始转账时持有资金的币种，不是结果展示币种。入金默认分组比较：

- 初始为港币：方案一、三。
- 初始为美元：方案二、四、五。

跨组比较需要计入前置换汇成本。可补充是否已有汇丰美国账户、是否完成嘉信与 Wise 美元账户关联；条件未知时会给出条件式建议。

可选参数 `rate` 表示每美元对应的港币数，默认 `7.8`，仅用于折算，不代表实际成交汇率。

## 提问示例

### 介绍方案

```text
请使用 us-stock-funding-fee-skill，介绍汇丰香港入金嘉信的五种方案，
说明各自的初始币种、资金路径和适用条件。
```

### 按已有资金和账户选路

```text
我在汇丰香港已有美元，没有汇丰美国账户，
但已在嘉信关联本人 Wise 美元账户，可以发起 ACH 拉取。
哪种入金方案适合我？
```

### 计算具体金额

```text
我有 100000 港币在汇丰香港，想入金嘉信。
请按参考模型比较方案一和方案三的成本，
使用 7.8 作为美元兑港币折算基准，并说明哪些费用尚未包含。
```

也可以使用参数格式：

```text
请按 us-stock-funding-fee-skill 计算：
direction=inflow
amount=10000
currency=USD
rate=7.82
请展示五种方案，只对初始币种匹配的方案比较成本，
并说明推荐所需的账户条件。
```

## 输出说明

完整介绍或比较展示五项方案；单项问题只展开相关路径。推荐依据初始币种、账户条件及同口径总成本，区分转账费、兑换费和汇差。仅在有助于选择时分析费用交叉点。

Wise 相关入金方案使用嘉信关联本人 Wise 美元账户后发起 ACH 拉取，与 Wise 主动向券商汇款不同。美元拉取段无换汇不代表港币起始路径全程无汇损。
