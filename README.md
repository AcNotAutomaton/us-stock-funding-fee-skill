# 跨境汇款手续费减免

一个用于比较内地、香港与美国账户汇款路径的 Codex skill，帮助选择适用的手续费减免方案，估算总成本与到账金额。仅提供分析，不执行转账。

## 内地汇款至香港

重点比较 **兴业寰宇人生卡 → 汇丰香港**：核对活动期前 30 笔汇款手续费、电讯费减免及购结汇优惠。

| 汇出银行 | 对应收款银行 | 通道 |
|---|---|---|
| 兴业寰宇人生卡 | 汇丰香港 | 跨境外币汇款 |
| 内地工行 | 工银亚洲 | 工银速汇 |
| 内地中行 | 中银香港 | 手机银行同名境外中行汇款 |
| 内地建行 | 建行亚洲 | 跨境直联汇款 |
| 汇丰中国 | 汇丰香港 | 环球转账 |
| 渣打中国 | 渣打香港 | 全球账户间汇款 |
| 恒生中国 | 恒生香港 | App 跨域转账 |
| 交行 | 建行亚洲 | 跨境支付通：人民币汇出、港币到账 |

以上为减免候选路线，并非无条件全程免费；账户资格、优惠期限、次数与代理行收费须分别确认。工行、中行、建行的内地端全免条件仍需核对本人当期优惠。详见 [内地汇款至香港](references/mainland-to-hong-kong.md)。

## 香港与美国资金路径

- **汇丰香港 → 嘉信**：按初始港币或美元比较五种入金方案，见 [路径目录](references/route-catalog.md)。嘉信 → 汇丰香港的反向路径仍待核实。
- **嘉信 → 华美美国账户**：比较 MoneyLink ACH 与美国境内电汇，见 [出金说明](references/schwab-to-east-west-bank.md)。
- **香港银行 → 华美美国账户**：比较直接经 Wise 汇款与恒生 Global Money+，见 [汇款说明](references/hong-kong-to-east-west-bank.md)。

## 使用示例

```text
请使用 us-stock-funding-fee-skill：
我在兴业寰宇人生卡有 10000 美元现汇，想汇入本人汇丰香港账户。
请说明手续费减免条件、可能的其他费用和预计到账金额。
```

比较费用时，请提供资金所在银行、初始币种、金额和已有账户。免费汇款不等于免费换汇；具体费用以当前银行规则和本人订单为准，汇款须符合真实用途及监管要求。
